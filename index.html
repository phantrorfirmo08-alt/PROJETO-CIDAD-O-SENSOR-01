📜 Termos de Uso & Privacidade (LGPD)

1. Termos de Uso e Funcionalidade: Este aplicativo opera como uma interface inteligente de consulta e suporte informativo. As respostas geradas pela assistente virtual têm caráter orientativo e educacional.

2. Proteção de Dados (Lei Federal nº 13.709/2018 - LGPD):
• Armazenamento Local: A chave de API e as preferências visuais (tema e tamanho de fonte) são salvas exclusivamente no armazenamento local do dispositivo do usuário (localStorage), sem envio para servidores intermediários do aplicativo.
• Privacidade: O aplicativo não coleta, rastreia ou armazena dados pessoais dos usuários em bases de dados externas. O processamento de consultas ocorre diretamente entre o navegador do usuário e o provedor de IA configurado.
